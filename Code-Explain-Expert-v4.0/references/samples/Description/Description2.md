# Description

## 中文版

格物（Gewu Deep Research）是一个基于 LangGraph 构建的开箱即用的多 Agent 深度研究系统，输入研究问题即可从需求澄清、研究简报、并行搜索、发现压缩到带引用 Markdown 报告的全流程自动化能力。其含金量在编排与稳定性：主管 Supervisor 子图拆解调度、多个研究员 Supervisor 子图并行搜索，Token 超限自动截断重试与异步并行检索、结构化输出自动重试、三层状态隔离与平台级 Supabase 认证鉴权。项目自带全套中文提示词与报告语言自适应，以及自研 React + Vite 实时可视化控制台（含无后端演示模式）支持 OpenAI 多模型与 Tavily、MCP 工具生态，适合快速搭建或二次工程化研究型 Agent

## English

Gewu Deep Research is a multi-agent deep research system that turns a question into a cited report. A supervisor subgraph decomposes tasks; parallel researchers search, synthesize, with token-limit recovery and Supabase auth. It ships a Chinese prompt suite and a self-built React live console, built on LangGraph with multi-provider LLM and MCP.
